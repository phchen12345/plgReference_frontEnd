# 網頁功能介紹

本網站是台灣職業籃球資料查詢前端，目前主要聚焦在 PLG 2025-26 賽季。使用者可以查看賽程、比分、收藏關注球隊，並進入單場比賽頁面查看完整 box score 與進階數據。

## 首頁：賽程總覽

首頁路由為 `/`，`/home` 也會顯示相同內容。

首頁主要提供 PLG 2025-26 賽季的賽程列表，包含已完賽與尚未開打的比賽。頁面上方會顯示目前載入的比賽數量，並提供球隊收藏與賽程篩選功能。

首頁會顯示的比賽資訊包含：

- 比賽日期與時間
- 比賽場館
- 主隊與客隊名稱
- 主隊與客隊 Logo
- 比賽階段，例如例行賽、季後賽或總冠軍賽
- 已完賽比分，未開賽賽事則顯示 `vs`

## 收藏球隊

首頁提供「選擇你關注的球隊」區塊，使用者可以勾選想追蹤的球隊。

收藏球隊後會有兩個效果：

- 頁首會顯示已收藏球隊的 Logo。
- 賽程篩選器可以切換到收藏球隊，只顯示與收藏球隊相關的比賽。

收藏資料會保存在瀏覽器本機儲存空間中，重新整理頁面後仍會保留。

## 賽程篩選

首頁賽程區塊提供下拉篩選功能，方便快速找到指定比賽。

目前支援的篩選方式：

- 顯示全部賽事
- 只顯示收藏球隊相關賽事
- 依單一球隊篩選賽事

篩選後的賽事會分成兩個區塊：

- 未來賽事：尚未開打的比賽
- 已完賽事：已結束且有比分與數據的比賽

已完賽事會依時間由新到舊排序，方便使用者優先查看最近完成的比賽。

## 賽事卡片

每一場比賽都會以卡片呈現。卡片包含時間、場館、賽事階段、雙方球隊與比分。

點擊任一賽事卡片後，會進入該場比賽的詳細頁：

```text
/games/[gameId]
```

例如某場比賽 ID 為 `123`，詳細頁路由會是：

```text
/games/123
```

## 單場賽事詳細頁

單場賽事詳細頁提供該場比賽的完整數據視覺化與 box score。頁面上方有返回首頁的連結，方便回到賽程列表。

詳細頁主要區塊包含：

- 比分看板
- 節次比分表
- 球隊得分分佈
- 團隊基本數據與進階數據
- 禁區、快攻、二次得分比例圖
- 球員基本數據與進階數據

若找不到指定比賽資料，頁面會進入 Next.js 的 not found 流程。

## 比分看板

比分看板會顯示該場比賽的核心資訊：

- 客隊與主隊名稱
- 客隊與主隊 Logo
- 最終比分
- 比賽日期與時間
- 比賽場館
- 裁判資訊

比分較低的一方會以較淡的顏色顯示，讓勝負結果更容易辨識。

## 節次比分表

節次比分表會列出主客隊每一節的得分，包含：

- Q1
- Q2
- Q3
- Q4
- 總分

這個區塊適合用來快速判斷比賽走勢，例如哪一節拉開比分、哪一隊下半場表現較好。

## 球隊得分分佈

球隊得分分佈區塊會用圖表比較主客隊不同球員類型的得分來源。

目前分為：

- 本土球員得分
- 洋將得分
- 外籍生得分

使用者可以透過這個區塊了解球隊得分是否依賴特定球員類型。

## 團隊數據

團隊數據區塊分為「基本數據」與「進階數據」兩張表，並支援切換不同比賽區間。

可切換的區間包含：

- 全場
- 上半場
- 下半場
- 各單節

基本數據包含：

- 得分
- 籃板，含進攻籃板與防守籃板
- 助攻
- 抄截
- 阻攻
- 失誤
- 投籃命中與命中率
- 兩分命中與命中率
- 三分命中與命中率
- 罰球命中與命中率

進階數據包含：

- 進攻次數 Poss
- 進攻效率 ORTG
- 防守效率 DRTG
- 淨效率 NETRTG
- 真實命中率 TS%
- 有效命中率 eFG%
- 節奏 Pace
- 助攻率 AST%
- 進攻籃板率 ORB%
- 失誤率 TOV%
- 效率值 EFF

部分進階數據欄位會提供公式說明，協助理解指標意義。

## 得分來源圓餅圖

詳細頁也提供三個得分來源圖表，用來比較主客隊在特定得分型態上的占比。

目前包含：

- 禁區得分
- 快攻得分
- 二次得分

這些圖表適合用來快速觀察球隊打法，例如是否偏重禁區攻擊、轉換快攻或進攻籃板後的二次進攻。

## 球員數據

球員數據區塊會分主隊與客隊顯示，每隊各有基本數據與進階數據表。

球員基本資訊包含：

- 背號
- 球員姓名
- 英文姓名
- 是否先發
- 上場時間

球員基本數據包含：

- 投籃命中與出手
- 三分命中、出手與命中率
- 罰球命中、出手與命中率
- 進攻籃板、防守籃板與總籃板
- 助攻
- 抄截
- 阻攻
- 失誤
- 個人犯規
- 得分
- Game Score
- 正負值

球員進階數據包含：

- 真實命中率 TS%
- 有效命中率 eFG%
- 三分出手率 3PAr
- 罰球率 FTr
- 進攻籃板率 ORB%
- 防守籃板率 DRB%
- 總籃板率 TRB%
- 助攻率 AST%
- 抄截率 STL%
- 阻攻率 BLK%
- 失誤率 TOV%
- 使用率 USG%
- 進攻效率 ORtg
- 防守效率 DRtg

表格欄位標題可顯示說明文字，方便使用者理解縮寫與公式。

## 明暗模式

頁首右側提供明暗模式切換按鈕。

使用者可以在淺色與深色介面之間切換，網站主要區塊、卡片、表格與文字顏色都會跟著調整。

## 資料更新與快取

前端資料來自後端 API。賽程與單場 box score 目前都設定 `revalidate: 60`，表示 Next.js 會以約 60 秒為單位重新驗證資料。

目前使用的 API：

- `GET /api/schedule?leagueCode=PLG&season=2025-26`
- `GET /api/games/:gameId/boxscore`

若 API 無法連線或環境變數未設定，首頁會顯示錯誤訊息，單場頁則可能進入找不到頁面的流程。
